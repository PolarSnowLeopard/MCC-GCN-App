# 账户与语言

本页介绍账户相关功能与语言偏好设置。

## 语言切换

每个页面右上角显示一个标注为 **`EN`** 或 **`中文`** 的切换按钮。

- 点击后整个界面在英文与简体中文之间切换。
- 偏好设置保存在浏览器本地存储中，后续访问默认使用上次选择的语言。
- 所有 UI 文本均已完整翻译，不会出现混合语言状态。

::: info
本文档站点有独立的语言切换器，位于文档导航栏。它与主应用的语言切换相互独立。
:::

## 退出登录

侧边栏底部，紧邻用户名和头像处，有一个**退出登录**图标（向外指的箭头；悬停时变红）。点击后终止当前会话并返回登录页面。

## 忘记密码

当前版本不包含自助密码重置功能。如忘记密码：

1. 联系平台管理员。
2. 管理员可通过服务器上的 Django 管理命令重置密码——操作步骤参见 [项目 README](https://github.com/PolarSnowLeopard/MCC-GCN-App#operations-cheatsheet)。

## 用户角色

角色显示在侧边栏用户名下方：

| 角色 | 权限 |
| --- | --- |
| **研究员** | 本手册中记录的所有工作流均可使用 |
| **管理员** | 与研究员相同，另有 `/admin/` Django 管理面板的访问权限 |

角色由管理员分配，无法通过界面自行更改。
