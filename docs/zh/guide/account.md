# 账户与语言

UI 各种边角功能的简短说明。

## 语言切换

每个页面右上角都有一个 `EN` 或 `中文` 的小按钮。

- 点击切换整个界面的语言。
- 选择会保存在浏览器中，下次访问保持上次的语言。
- 平台所有内容都已完整翻译，不会出现中英混排。

::: tip
本文档站点也有自己的语言切换按钮（位于文档顶栏右上）。它和主应用的切换是相互独立的。
:::

## 退出登录

侧边栏底部，紧邻你的用户名和头像：

- 一个 **向外箭头** 图标（悬停时变红），点击退出登录并返回登录页。

## 忘记密码

平台当前版本没有自助密码重置入口。如果忘记密码：

- 联系管理员。
- 管理员可以从服务器上用一条 Django 管理命令重置 — 详见 [项目 README](https://github.com/PolarSnowLeopard/MCC-GCN-App#operations-cheatsheet)。

## 角色

侧边栏用户名下方会显示你的角色：

- **研究员** — 标准角色，文档涵盖的所有功能你都能用。
- **管理员** — 与研究员相同，外加 Django 后台（`/admin/`）的访问权限。绝大多数用户没有此角色。

无法从 UI 自助修改角色——这由管理员管理。
