# 批量筛选

**批量筛选**用于在单次提交中评估大量分子对。平台将任务排入队列，通过 Celery 工作进程异步处理，完成后呈现完整结果表。

::: tip 导航
在侧边栏选择 **批量筛选**。
:::

## 工作流选择

| 工作流 | 适用场景 |
| --- | --- |
| [单次预测](./predict) | 单对分子；即时交互式结果 |
| **批量筛选** | 数十至数千对分子，通过 CSV 或粘贴文本输入 |

## 操作流程

### 1. 选择模型

模型下拉菜单与预测页面共享，列出当前账号可见的所有模型。日常使用推荐内置 `MCC-GCN v1`。

### 2. 提供输入数据

**数据输入**下方的分段控件提供两种模式：

#### 文本输入

在文本框中直接粘贴分子对，每行一对：

```
api_smiles,coformer_smiles
```

示例：

```
CCO,O=C(O)c1ccccc1O
O=C(O)CCC(=O)O,Nc1ccnc(N)[n+]1[O-]
```

空行及不含恰好两个逗号分隔 SMILES 的行将被静默丢弃。

#### CSV 上传

点击或拖拽 `.csv` 文件到上传区。

格式要求：

```csv
api_smiles,coformer_smiles
CCO,O=C(O)c1ccccc1O
O=C(O)CCC(=O)O,Nc1ccnc(N)[n+]1[O-]
```

- **表头行**：可选。若第一行包含 `smiles` 字样（不区分大小写），将被视为表头并跳过。
- **列**：恰好两列 — `api_smiles` 和 `coformer_smiles`。
- **编码**：UTF-8。

::: tip
点击上传区旁的 **下载模板** 按钮，可获取包含两行示例的模板文件。
:::

### 3. 提交

点击 **开始筛选**。

- 表单将校验已选模型且至少包含一对有效分子。
- 提交成功后显示确认提示：*"批量任务已提交，请到历史记录查看结果"*。

### 4. 监控进度

页面显示进度卡片，呈现以下状态之一：

| 状态 | 含义 |
| --- | --- |
| **排队中** | 任务等待 Celery 工作进程处理（正常负载下通常不到 1 秒） |
| **运行中** | 推理进行中 |

::: warning
离开批量筛选页面将停止页内进度轮询。任务本身**继续在服务器上运行**。离开后可通过 [历史记录](./history) 查看结果。
:::

### 5. 查看结果

任务完成后显示结果表：

| 列 | 说明 |
| --- | --- |
| **#** | 行号（从 1 开始） |
| **API SMILES** | 输入回显（悬停查看完整字符串） |
| **Coformer SMILES** | 输入回显 |
| **预测** | 彩色标签：`Negative`（灰）、`Salt`（琥珀）、`Cocrystal`（绿）、`Solvate`（蓝） |
| **置信度** | 最大类别概率，以百分比表示 |

各行按预测类别浅色着色，便于快速视觉扫描。

### 6. 导出

点击结果卡片标题栏的 **导出 CSV**。下载的 `batch_results.csv` 包含：

```
API SMILES, Coformer SMILES, Prediction, Label, Confidence
```

## 最佳实践

- **先验证少量样本。** 提交大规模 CSV 前，先通过 [单次预测](./predict) 测试几对代表性分子。在第 1 行发现表头错误远比在第 5,000 行发现要经济。
- **使用规范 SMILES。** RDKit 无法解析任一分子的行将产生空结果。PubChem 的 Canonical SMILES 几乎不会被拒绝。
- **每次提交控制在约 5,000 对以内。** 默认管线使用纯 CPU 推理。更大规模筛选请拆分为多次顺序提交——所有结果均出现在同一 [历史记录](./history) 页面。
