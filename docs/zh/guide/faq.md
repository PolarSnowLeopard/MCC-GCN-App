# 常见问题

最常被问到的问题汇总。

## 登录与账户

### 我忘记密码了。

当前版本没有自助重置。请联系管理员，他们可以在服务器上用一条命令直接重置（详见 [项目 README](https://github.com/PolarSnowLeopard/MCC-GCN-App#operations-cheatsheet)）。

### 登录成功了但侧边栏是空的。

很可能你看的是 **登录** 或 **注册** 页（这两个页面不显示侧边栏）。登录后才会进入主工作台。

## SMILES 与输入

### 系统说我的 SMILES "无效"，怎么回事？

平台用 RDKit 解析 SMILES。"无效" 意味着 RDKit 无法把它解析成分子图。最快的修复办法：

- 从 PubChem 复制该分子的 *Canonical SMILES*，粘贴使用。

### 我有一个中文化合物名，名称查询提示找不到。

名称查询走的是 PubChem，PubChem 只识别英文名和 CAS 号。三种解决：

- 把名字翻译成英文，或者
- 改用 CAS 号，或者
- 直接粘贴 SMILES（切到 **SMILES 输入** Tab）。

### 我能预测多组分 SMILES（`X.Y`）形式的盐吗？

可以，RDKit 接受这种写法，但模型会把整个 `X.Y` 当作一个分子处理。要得到最佳结果，请把盐拆到 **API** 与 **Coformer** 两个槽里。

## 预测

### *置信度* 到底是什么意思？

它是 4 类概率的 **最大值**。如果概率向量是 `[0.05, 0.05, 0.85, 0.05]`，置信度就是 `85.0%`。完整向量会显示在结果 Hero 块下方。

### 平台说做了"双向推理"是什么意思？

分子对 `(A, B)` 和 `(B, A)` 在平台的特征化下并不严格对称。平台内部会同时跑两种顺序、对 softmax 取平均。你不需要手动交换。

## 批量筛选

### 我的批量任务一直 *排队中*。

两种可能：

1. Celery worker 排队消化中——等一分钟后刷新。
2. Celery worker 没在跑。请管理员检查 `docker compose logs -f celery`。任务本身不会丢失，worker 恢复后会继续。

### 我回到批量页面后看不到结果了。

结果表是从页内的轮询状态渲染的，离开页面就重置了。要重新打开已完成的批量任务，请去 **历史记录 → 预测任务**，点对应一行。

### 一次最多能交多少对？

没有硬上限，但默认管线是 CPU 推理。一次提交 ~5000 对以下比较舒适；超大筛选请拆成多次顺序提交。

## 微调

### 微调失败提示 *"Need at least 2 valid training samples"*。

要么你 CSV 中两侧 SMILES 都能解析的行不到 2 条，要么 label 不是 0–3 的整数。展开失败任务的详情，可以看到解析器具体拒绝了哪些行。

### 训练好慢，能怎么办？

管线运行在 CPU。两条提速思路：

- **小数据集** 先把流程跑通，再扩到大数据集。
- **少 epoch** — 默认 50 比较保守，多数小数据集远在此之前就收敛。

如果管理员部署了 GPU 版本，训练会自动快很多。

### 我微调出来的模型在哪？

会出现在 [模型管理](./models) 页面，状态为 **草稿**。可以从同一展开行 [测试](./finetune#测试结果)，确认满意后再 [发布](./finetune#发布结果)。

### 失败任务能删除吗？

失败的微调任务不会产出模型文件，没什么可删的。失败任务本身仍保留在 [历史记录](./history) 中作为记录。如果想彻底清掉，请联系管理员。

## 模型

### 为什么 *内置* 模型不能删？

内置模型受保护。UI 里拒绝删除，API 也会返回错误。它们是平台对所有用户的默认配置。

### 上传的 `.pth` 加载不出来。

最常见的原因是你保存的是整个模型对象，而不是 state dict：

```python
# 错误 — 保存了整个对象
torch.save(model, 'model.pth')

# 正确 — 只保存参数
torch.save(model.state_dict(), 'model.pth')
```

平台只接受第二种形式，且权重必须匹配项目的 `GCNNet` 结构。详见 [`backend/mcc_gcn/models/gcn.py`](https://github.com/PolarSnowLeopard/MCC-GCN-App/blob/main/backend/mcc_gcn/models/gcn.py)。

## 界面与语言

### 怎么切换中英文？

页面右上角的 `EN` / `中文` 小按钮。整个 UI 即时切换。选择会记忆在浏览器中。

### 页面看起来怪怪的 / 样式没了。

强制刷新：`Ctrl/Cmd + Shift + R`。如果问题持续 — 特别是 Django `/admin/` 后台 — 请告知管理员，这通常是部署阶段静态文件的问题。
