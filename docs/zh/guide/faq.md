# 常见问题

按主题分类的常见问题解答。

## 登录与账户

### 我忘记了密码。

当前版本不提供自助密码重置。请联系管理员——他们可通过一条管理命令在服务器上重置密码（参见 [项目 README](https://github.com/PolarSnowLeopard/MCC-GCN-App#operations-cheatsheet)）。

### 登录后侧边栏为空。

你很可能仍处于登录或注册页面，这些页面不显示侧边栏。完成登录流程即可进入主工作区。

## SMILES 与输入

### 平台提示我的 SMILES "无效"。

平台使用 RDKit 解析 SMILES。"无效"结果表示 RDKit 无法从输入字符串构建分子图。推荐修复方式：

- 从 [PubChem](https://pubchem.ncbi.nlm.nih.gov/) 获取该化合物的 *Canonical SMILES* 并直接粘贴。

### 名称/CAS 查询返回"未找到分子"。

查询功能依次查询三个上游数据库：**PubChem**、**NIH NCI Cactus** 和 **OPSIN**。若均未识别：

- 核对英文化合物名称的拼写。
- 改用 **CAS 号**。
- 最后可切换到 **SMILES 输入** 标签页直接粘贴 SMILES。

::: info
上游解析器均不支持中文化合物名称。请使用英文名称或 CAS 号。
:::

### 能否预测以多组分 SMILES（`X.Y`）形式书写的盐？

可以——RDKit 会解析它们。但模型将整个 `X.Y` 作为单一分子图特征化。为获得更准确的结果，建议将盐的组分分别输入 **API** 和 **Coformer** 字段。

## 预测

### "置信度"具体代表什么？

置信度是四个类别概率的**最大值**。例如概率向量 `[0.05, 0.05, 0.85, 0.05]` 对应 `85.0%` 的置信度。完整向量始终显示在主要结果下方。

### 什么是"双向推理"？

由于平台的特征化方案，分子对 `(A, B)` 和 `(B, A)` 构建的分子图结构不同。为缓解这种不对称性，平台对两种排列分别评估并对 softmax 向量取平均。此过程自动完成。

## 批量筛选

### 批量任务一直停留在"排队中"。

两种可能原因：

1. **工作进程积压** — Celery 工作进程正在处理先前任务。等待几分钟后刷新。
2. **工作进程不可用** — Celery 进程可能已停止。请联系管理员检查 `docker compose logs -f celery`。任务不会丢失——工作进程恢复后将继续执行。

### 返回批量筛选页面后看不到结果？

结果表从页内轮询状态渲染，离开页面后重置。要重新打开已完成的批量任务，请进入 **历史记录** 选择对应行。

### 一次最多能提交多少对？

没有强制上限。但默认推理管线仅使用 CPU。约 5,000 对以内的提交可在合理时间内完成。更大规模筛选请拆分为多次顺序提交。

## 微调

### 微调失败并提示"Need at least 2 valid training samples"。

此错误表示提交的 CSV 中两侧 SMILES 均有效**且**标签为 `{0, 1, 2, 3}` 的行不足两条。展开失败任务的详情视图可查看被拒绝的行。

### 训练速度慢，如何加速？

训练管线默认使用 CPU。两种实用方案：

- **原型验证阶段使用较小数据集**；配置验证后再扩大规模。
- **减少 epoch 数** — 默认的 50 较为保守。许多小数据集远在此阈值之前即已收敛。

若管理员部署了 GPU 支持的构建版本，训练将自动大幅加速。

### 微调后的模型出现在哪里？

注册在 [模型管理](./models) 页面，状态为**草稿**。可从任务详情视图 [测试](./finetune#测试)，满意后 [发布](./finetune#发布)。

### 能否删除失败的微调任务？

失败任务不产出模型文件，模型侧无需删除。任务记录本身保留在 [历史记录](./history) 中用于审计。如需永久移除，请联系管理员。

## 模型

### 为什么无法删除内置模型？

内置模型受保护。UI 和 API 均拒绝删除请求。这些模型作为平台所有用户的共享默认配置。

### 上传的 `.pth` 文件加载失败。

最常见的原因是保存了完整模型对象而非 state dict：

```python
# 错误 — 序列化了整个模型对象
torch.save(model, 'model.pth')

# 正确 — 仅序列化可学习参数
torch.save(model.state_dict(), 'model.pth')
```

平台要求第二种形式。state dict 须兼容项目的 `GCNNet` 架构（参见 [`backend/mcc_gcn/models/gcn.py`](https://github.com/PolarSnowLeopard/MCC-GCN-App/blob/main/backend/mcc_gcn/models/gcn.py)）。

## 界面与语言

### 如何切换中英文？

点击任意页面右上角的 **`EN`** / **`中文`** 切换按钮。整个界面即时切换。偏好设置存储在浏览器本地存储中，跨会话持久有效。

### 页面样式异常或缺失。

执行强制刷新：`Ctrl + Shift + R`（Windows/Linux）或 `Cmd + Shift + R`（macOS）。若问题持续——特别是 `/admin/` Django 管理面板——请报告给管理员，这通常是部署层面的静态文件问题。
