# 模型微调

当内置模型无法充分捕获你化学体系的特征时，可以在自有标注数据集上**微调**基础模型，产出领域专属预测器。

::: tip 导航
在侧边栏选择 **微调**。
:::

## 微调机制

你提供一份包含已知分类的分子对 CSV。平台将：

1. 加载所选**基础模型**权重；
2. 冻结前层图卷积层，仅重训练最后的全连接层；
3. 保存**平衡验证准确率**最高的检查点；
4. 在你的账号下注册新模型，状态为**草稿**。

草稿模型仅对你可见。评估完成后可 [发布](#发布) 使其对其他用户可见。

## 页面布局

页面分为左右两栏：

- **左栏** — *微调配置* 表单
- **右栏** — *微调任务* 列表（当前与历史任务）

## 步骤 1 — 准备训练数据

表单要求包含三列的 CSV：

```csv
api_smiles,coformer_smiles,label
CCO,O=C(O)c1ccccc1O,2
c1ccccc1,CC(=O)O,0
```

标签编码：

| 值 | 类别 |
| :---: | --- |
| `0` | Negative |
| `1` | Salt |
| `2` | Cocrystal |
| `3` | Solvate |

::: tip
点击上传区旁的 **下载模板** 按钮获取模板 CSV。
:::

::: warning 最低数据要求
训练管线要求**至少 2 行**两侧 SMILES 均可成功解析且标签为 `{0, 1, 2, 3}` 中有效整数的数据。为使迁移学习有实际意义，建议准备**数十至数百条**标注数据，并保持合理的类别平衡。
:::

## 步骤 2 — 配置并提交

填写左栏表单：

| 字段 | 说明 |
| --- | --- |
| **基础模型** | 初始化起点。标准选择为内置 **MCC-GCN Pretrained v1**。 |
| **任务名称** | 描述性标识（如 `api-screening-2026-04`），生成的模型文件继承此名称。 |
| **训练数据** | 通过拖拽或文件选择器上传 CSV。 |

#### 高级参数

展开 **高级参数** 区域可查看其他控件。默认值适用于大多数场景——仅在有充分理由时修改。

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| **Epochs** | `50` | 完整遍历训练数据的轮次 |
| **Batch Size** | `16` | 每次梯度更新的样本数 |
| **Learning Rate** | `0.0003` | 优化器步长 |

其他参数（`weight_decay`、`train_layers`）使用安全默认值。如需调整，请咨询管理员。

点击 **提交微调任务** 将作业加入队列。

## 步骤 3 — 监控进度

提交的任务出现在右侧面板顶部。点击某行展开详情：

| 状态 | 说明 |
| --- | --- |
| **排队中** | 等待 Celery 工作进程 |
| **运行中** | 训练进行中；第一个 epoch 完成后开始流式输出日志 |
| **已完成** | 训练完成；显示最佳验证指标与操作按钮 |
| **失败** | 发生错误；显示完整 traceback（常见原因：CSV 格式不正确、SMILES 不可解析） |

::: tip
训练期间任务列表自动轮询更新。也可点击面板标题栏的 **刷新** 手动触发。
:::

## 步骤 4 — 评估与使用结果

任务完成后，展开的详情视图提供两个操作。

### 测试

点击 **测试模型** 打开内联评估对话框：

1. 输入一对已知结果的 API 和 Coformer SMILES。
2. 点击 **预测**。
3. 查看四分类概率柱状图，评估微调模型是否符合预期。

### 发布

默认情况下生成的模型为**草稿**状态——仅对你可见。

要使其对平台所有用户可用：

1. 点击 **发布模型**。
2. 确认。状态标签从 `Draft` 变更为 `Published`。

也可稍后在 [模型管理](./models) 页面发布。

## 阅读训练日志

每个 epoch 产出一行如下格式的日志：

```
Epoch 12/50 | train_loss=0.2517 train_acc=0.8923 | val_loss=0.3104 val_acc=0.8421 val_bacc=0.8055
```

| 指标 | 含义 |
| --- | --- |
| `train_loss` / `train_acc` | 训练集上的交叉熵损失与准确率 |
| `val_loss` / `val_acc` | 20% 留出验证集上的相同指标 |
| `val_bacc` | 平衡验证准确率——检查点选择准则 |

健康的训练过程表现为 `val_bacc` 在前若干 epoch 持续上升后趋于平稳。若 `train_acc` 继续上升而 `val_acc` 开始下降，说明模型过拟合。应减少 epoch 数或增大数据集。
