# 5 分钟快速上手

带你完成注册、登录和第一次预测。大约五分钟。

## 1. 打开平台

在浏览器中访问管理员提供的地址，例如：

```
http://<你的服务器>:8880/
```

页面会落在 **登录** 页面。

## 2. 注册账号

在登录表单下方点击 **注册**（或链接 *"还没有账号？注册"*）。

注册表单：

| 字段 | 输入内容 |
| --- | --- |
| **用户名** | 任意唯一字符串，字母 / 数字 / 下划线 |
| **邮箱** | 真实邮箱，后续找回密码时会用到 |
| **密码** | 至少 6 位 |
| **确认密码** | 再输一次密码 |

点击 **注册**。注册成功后会跳回登录页。

::: tip
如果管理员已经为你创建了账号，跳到下一步即可。
:::

## 3. 登录

输入用户名和密码，点击 **登录**。

进入 **单次预测** 页面（主工作台）。左侧侧边栏有 5 个工作流：

- 🧪 **预测**
- 📊 **批量筛选**
- 🎯 **微调**
- 🕘 **历史记录**
- 📚 **模型**

## 4. 跑一次预测

最快的路径：在表单顶部点 **加载示例数据 (KPX + 水杨酸)**，两个分子字段会自动填入论文实验集中的有效 SMILES。

然后：

1. 在 **选择模型** 下拉框选 **MCC-GCN v1**（已微调的生产模型，开箱可用）。
2. 点 **预测**。
3. 大约 1 秒后右侧面板出现：
   - 预测标签（`Cocrystal` / `Salt` / `Solvate` / `Negative`）
   - 4 类概率向量
   - 置信度百分比

至此你已经完成了第一次预测。

## 5. 接下来做什么

- 想换 **自己的分子对**？看 [单次预测](./predict)：SMILES 输入、名称/CAS 查询、结果如何看。
- 有大量分子对要试？跳到 [批量筛选](./batch)。
- 想要适配你自己数据集的模型？看 [模型微调](./finetune)。
- 想了解侧边栏每个页面？看 [界面总览](./interface)。
