# 快速上手

本章引导你完成账号创建、登录及首次预测。预计耗时不超过五分钟。

## 1. 打开平台

在浏览器中访问管理员提供的地址：

```
https://<your-domain>/
```

页面将展示**登录**界面。

::: tip HTTPS
平台通过 HTTPS 提供服务，HTTP 请求会被自动重定向。
:::

## 2. 创建账号

点击登录表单下方的 **注册** 链接。

| 字段 | 要求 |
| --- | --- |
| **用户名** | 唯一；支持字母、数字与下划线 |
| **邮箱** | 有效邮箱地址（用于管理员联系） |
| **密码** | 至少 6 位 |
| **确认密码** | 须与密码一致 |

点击 **注册**。成功后将跳转至登录页面。

::: tip
如果管理员已为你创建账号，可直接跳至登录步骤。
:::

## 3. 登录

输入用户名和密码，点击 **登录**。

进入默认工作页面——**单次预测**。左侧边栏提供五个核心工作流的入口：

- **预测** — 单分子对推理
- **批量筛选** — 基于 CSV 的批量推理
- **微调** — 自有数据的迁移学习
- **历史记录** — 所有任务的审计追踪
- **模型** — 模型库管理

侧边栏底部的 **用户手册** 链接可打开本文档站点。

## 4. 运行首次预测

最快路径是使用内置实验数据集：

1. 在预测页面切换到 **论文样本** 标签页。
2. 从两个下拉菜单中分别选择 **API 分子** 和 **Coformer** — 这些是已发表研究中的 64 组实验分子对。
3. 模型会自动选定。点击 **预测**。
4. 右侧面板将显示：
   - 预测的类别标签（如 `Cocrystal`）
   - 四分类概率分布
   - 置信度百分比（最大类别概率）

至此，你已完成首次预测。
