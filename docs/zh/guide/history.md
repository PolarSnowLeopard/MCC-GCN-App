# 历史记录

通过平台提交的每个预测和微调任务均自动持久保存。**历史记录**页面提供对所有过往结果的访问。

::: tip 导航
在侧边栏选择 **历史记录**。
:::

## 标签页

页面分为两个标签页：

| 标签页 | 内容 |
| --- | --- |
| **预测任务** | 单次预测与批量筛选提交 |
| **微调任务** | 微调作业 |

两个标签页仅显示**你自己的**任务。其他用户的历史不可见。

## 预测任务

每行包含：

| 列 | 说明 |
| --- | --- |
| **ID** | 任务编号 |
| **类型** | `单次` 或 `批量` |
| **状态** | `排队中` · `运行中` · `已完成` · `失败` |
| **创建时间** | 提交时间戳 |
| **详情** | 打开结果面板 |

点击 **详情** 可查看保存的输入与结果：

- **单次**预测展示 API、Coformer、预测类别及四分类概率分布。
- **批量**预测逐条展示 API、Coformer、预测类别和置信度。
- 某行预测失败时，表格会显示对应的失败原因。
- 任务处于排队状态或执行失败时，已提交的输入仍可查看。

已完成的批量结果可通过 **导出 CSV** 下载。文件包含 API、Coformer、预测编号、类别、置信度及失败原因。

## 微调任务

每行包含：

| 列 | 说明 |
| --- | --- |
| **任务名称** | 提交时指定的名称 |
| **状态** | `排队中` · `运行中` · `已完成` · `失败` |
| **创建时间** | 提交时间戳 |
| **详情** | 打开已保存的任务信息与当前状态 |

如需测试或发布已完成的微调模型，请前往 [模型微调](./finetune) 页面。

## 注意事项

- **任务停留在排队状态**：Celery 工作进程可能超载或已停止。请联系管理员。任务不会丢失——工作进程恢复后将继续执行。
- **已删除模型不影响历史记录**：预测结果独立于权重文件存储。即使产出结果的模型已被删除，历史结果仍可查看。
