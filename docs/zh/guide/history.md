# 历史记录

每次提交的预测任务和微调任务都会被自动归档。**历史记录** 页面就是回溯它们的地方。

::: tip 进入页面
点侧边栏 🕘 **历史记录**。
:::

## 两个 Tab

页面顶部两个 Tab：

| Tab | 显示内容 |
| --- | --- |
| **预测任务** | 你的 *单次预测* 与 *批量筛选* 任务 |
| **微调任务** | 你的 *微调* 任务 |

两个 Tab 都只展示属于你自己的任务——其他用户的历史不可见。

## 预测任务

每行展示：

| 列 | 说明 |
| --- | --- |
| **类型** | `单次` 或 `批量` |
| **状态** | `排队中` / `运行中` / `已完成` / `失败`（同步的单次预测会直接显示已完成） |
| **创建时间** | 时间戳 |
| **详情** | 点击展开结果面板 |

点 **详情** 重新打开结果：

- **单次** 预测会展示当时预测页右栏的全部内容（4 类概率、两侧 SMILES、使用的模型）。
- **批量** 预测会展示完整结果表，颜色编码与提交时一致。

页面顶部的类型筛选可以只看 *单次* 或 *批量*。

## 微调任务

每行展示：

| 列 | 说明 |
| --- | --- |
| **任务名称** | 提交时填写的名称 |
| **状态** | `排队中` / `运行中` / `已完成` / `失败` |
| **创建时间** | 时间戳 |
| **详情** | 点击展开日志和操作按钮 |

展开详情可以看到完整的 per-epoch 训练日志和与 [微调页](./finetune) 一致的 **测试模型** / **发布模型** 按钮。

## 小技巧

- **状态卡在排队中？** 要么 Celery worker 在排队消化，要么干脆没在跑。告知管理员即可。任务本身不会丢失，worker 恢复后会继续。
- **已经删除模型的旧预测仍然可读** —— 结果数据是独立保存的，与权重文件解耦。
