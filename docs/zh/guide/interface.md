# 界面总览

本页是应用布局与常用 UI 元素的参考手册。

## 布局

界面由三个区域组成：

| 区域 | 位置 | 功能 |
| --- | --- | --- |
| **侧边栏** | 左侧，深色背景 | 工作流导航、用户信息、退出登录 |
| **顶栏** | 右上方 | 语言切换 |
| **主内容区** | 中央 | 当前工作流页面 |

## 侧边栏底部

侧边栏底部显示：

- 你的**头像**（用户名首字母）
- **用户名**与**角色**（`研究员` 或 `管理员`）
- **退出登录**按钮（向外箭头图标，悬停时变红）

## 语言切换

位于每个页面的右上角：

- **`EN` / `中文`** — 实时切换中英文界面。偏好设置保存在浏览器本地存储中，跨会话持久有效。

## 通用页面元素

大多数工作流页面共享以下构件：

| 元素 | 说明 |
| --- | --- |
| **页面标题** | 主内容区顶部的加粗标题 |
| **页面描述** | 标题下方的简短说明文字 |
| **内容卡片** | 带浅阴影的白色面板，每张卡片承载一个逻辑单元（输入、配置或结果） |
| **主操作按钮** | 蓝色；触发当前工作流的核心操作 |
| **危险操作按钮** | 红色；执行前始终要求确认 |

交互模式一致：阅读标题 → 填写卡片字段 → 点击主按钮 → 查看输出。
