# 界面总览

UI 各部分的速查表。

## 整体布局

应用界面分为三个区域：

| 区域 | 作用 |
| --- | --- |
| **侧边栏**（左侧深色） | 工作流导航 + 个人信息 + 退出登录 |
| **顶栏**（右上） | 语言切换（`EN` / `中文`） |
| **主内容区** | 当前工作流页面 |

## 侧边栏菜单

| 图标 | 名称 | 文档 |
| --- | --- | --- |
| 🧪 | 预测 | [单次预测](./predict) |
| 📊 | 批量筛选 | [批量筛选](./batch) |
| 🎯 | 微调 | [模型微调](./finetune) |

当前激活页面会用蓝色高亮。

## 侧边栏底部

侧边栏底部显示：

- 你的 **头像**（用户名首字母）
- **用户名**
- **角色**（`研究员` 或 `管理员`）
- 一个 **退出登录** 的箭头按钮

## 顶栏

每个页面右上角都有：

- **`EN` / `中文`** — 实时切换整站语言。选择会保存在浏览器中，下次访问保持上次的语言。

## 通用页面元素

大部分工作流页面都共享相同的构件：

- **页面标题** — 顶部加粗的大字。
- **页面描述** — 标题下方的小字说明。
- **内容卡片** — 白色背板带浅阴影，每张卡片承载一组逻辑（输入 / 配置 / 结果）。
- **操作按钮** — 主操作按钮是蓝色的；危险操作（如删除）是红色的，且总会要求确认。

只要认识这几样，每个页面的使用方式都是一样的：读标题 → 填卡片 → 点主按钮 → 看结果。
