# 系统简介

MCC-GCN 是一个用于 **多组分晶体（MCC）预测** 的 Web 平台。给定两个分子，模型给出它们最可能的共结晶形式。

## 你能用它做什么

| 工作流 | 产出 |
| --- | --- |
| **单次预测** | 一对分子的 4 分类标签和概率向量 |
| **批量筛选** | 同样的预测在 CSV 给出的成千上万对分子上批量执行 |
| **模型微调** | 基于内置基座，在你自己的标注数据上训练出新模型 |
| **模型管理** | 上传、发布、共享、删除你的权重文件 |
| **历史记录** | 所有提交过的任务的完整审计 |

## 四个预测类别

模型对每一对分子给出以下四种类别之一：

| 标签 | 含义 |
| --- | --- |
| `Negative` | 这两个分子不会形成多组分晶体 |
| `Salt` | 形成盐 |
| `Cocrystal` | 形成共晶 |
| `Solvate` | 形成溶剂化物 |

四个类别的概率之和始终为 1。界面上显示的标签就是概率最高的那一类；任何预测结果面板里都能读到完整的概率向量。
