# 系统简介

MCC-GCN 是一个基于 Web 的**多组分晶体（MCC）预测平台**。给定一对分子——活性药物成分（API）与共晶配体（Coformer），底层的图卷积网络将预测它们最可能的共结晶形式。

## 平台功能

| 工作流 | 输出 |
| --- | --- |
| **单次预测** | 一对分子的四分类标签及逐类别概率向量 |
| **批量筛选** | 对 CSV 提供的成百上千对分子执行相同预测 |
| **模型微调** | 基于内置主干在用户自有标注数据上训练新模型 |
| **模型管理** | 上传、发布、共享或删除权重文件 |
| **历史记录** | 所有已提交任务的完整审计追踪 |

## 预测类别

模型对每对分子输出以下四个类别之一：

| 编号 | 标签 | 含义 |
| :---: | --- | --- |
| 0 | **Negative** | 该分子对不预期形成多组分晶体 |
| 1 | **Salt** | 最可能形成质子转移盐 |
| 2 | **Cocrystal** | 最可能形成共晶（非离子型） |
| 3 | **Solvate** | 最可能形成溶剂化物 |

四个类别的概率总和恒为 1。界面显示的标签对应概率最高的类别；完整概率向量可在任何结果面板中查看。

::: info 双向推理
特征化步骤对分子顺序并非严格对称。为此，平台内部同时评估 `(API, Coformer)` 和 `(Coformer, API)` 两种排列，并对 softmax 向量取平均。此过程自动完成，无需用户干预。
:::
