# 模型管理

**模型** 页面是你的模型库——平台上所有可用的权重文件都在这里。

::: tip 进入页面
点侧边栏 📚 **模型**。
:::

## 你看到了什么

页面是卡片网格，一张卡片对应一个模型。每张卡片包含：

- 一个彩色字母徽标 — `P` 表示 **预训练（Pretrained）**，`F` 表示 **微调（Fine-tuned）**。
- **模型名称** 和一行 **描述**。
- **类型**（`Pretrained` / `Fine-tuned`）和 **类别数**。
- **状态 Tag**：
  - `Built-in`（灰色）— 系统内置模型，不可删除。
  - `Draft`（橙色虚线边框）— 你自己的模型，仅自己可见。
  - `Published`（绿色）— 你自己的模型，已对其他用户可见。
- **创建时间**。
- 视情况出现的卡片操作：**发布** 与 **删除**。

## 可见性规则

某个用户看见某模型的条件 —— **任意一条** 命中即可：

- 模型属于该用户；
- 模型为 **内置**；
- 模型已 **发布**。

也就是说：

- 你自己的 *草稿* 模型在发布前只有你能看到。
- 你看不到其他用户的草稿。
- 内置模型对所有人可见。

## 常见操作

### 上传模型

如果你在外部用 PyTorch 训练好了 `.pt` / `.pth` 文件（且符合项目的 `GCNNet` 结构）：

1. 点页面右上角 **上传模型** 按钮。
2. 填写表单：
   | 字段 | 说明 |
   | --- | --- |
   | **模型名称** | 必填，自由命名 |
   | **描述** | 可选 |
   | **模型类型** | `Pretrained` 或 `Fine-tuned`（必填） |
   | **类别数** | 该权重训练时的输出类别数。默认 `4`。 |
   | **模型文件** | `.pt` / `.pth` 权重文件（拖拽或点击） |
3. 点 **上传**。

新卡片以 **草稿** 状态出现，仅你可见。需要分享时再点 **发布**。

::: warning 仅支持 state_dict
平台期望的是与项目 `GCNNet` 结构兼容的 **state dict**（详见 [`backend/mcc_gcn/models/gcn.py`](https://github.com/PolarSnowLeopard/MCC-GCN-App/blob/main/backend/mcc_gcn/models/gcn.py)）。如果你保存时用了 `torch.save(model, ...)` 而不是 `torch.save(model.state_dict(), ...)`，加载时会失败。
:::

### 发布模型

让某个草稿模型对平台其他用户可见：

1. 找到目标卡片。
2. 点 **发布** 按钮。
3. 状态 Tag 从 `Draft` 切换为 `Published`。

发布是单向的；如果想撤回为私有，请联系管理员。

### 删除模型

针对你自己（非内置）的模型：

1. 点卡片上的 **删除** 按钮。
2. 确认。

::: warning
- **内置模型不可删除**。
- 删除会移除服务器上的权重文件。已经用该模型生成的 [历史记录](./history) 仍可阅读，但你不能再用同名模型重跑。
:::

## 卡片是空的？

如果看到空状态的提示（*"暂无模型，点击上方按钮上传"*），说明：

- 你还没有自己的模型；**且**
- 没有内置模型（管理员没运行 `seed_builtin_model`）。

正常部署应该至少看到 2 个内置模型。如果没有，请告知管理员补一步初始化。
