# 模型管理

**模型**页面是集中的模型库，平台上所有可用于预测的权重文件——内置、微调或外部上传——均在此列出。

::: tip 导航
在侧边栏选择 **模型**。
:::

## 模型卡片

每个模型以卡片形式呈现，包含以下信息：

| 元素 | 说明 |
| --- | --- |
| **字母徽标** | `P`（预训练）或 `F`（微调），带颜色区分 |
| **名称与描述** | 创建时设定的自由文本元数据 |
| **类型** | `Pretrained` 或 `Fine-tuned` |
| **类别数** | 模型输出维度（默认 4） |
| **状态** | `Built-in`（灰色）· `Draft`（琥珀色虚线边框）· `Published`（绿色） |
| **创建时间** | 时间戳 |
| **操作** | **发布** 和/或 **删除**（视情况出现） |

## 可见性规则

用户可见某模型的条件——满足**任一**即可：

- 模型属于该用户。
- 模型为**内置**。
- 模型已**发布**。

含义：

- 你的*草稿*微调模型在发布前仅自己可见。
- 其他用户的草稿对你不可见。
- 内置模型对所有用户可见。

## 常见操作

### 上传模型

如果你有外部训练的 `.pt` 或 `.pth` 权重文件，且兼容项目的 `GCNNet` 架构：

1. 点击右上角的 **上传模型**。
2. 填写表单：

| 字段 | 说明 |
| --- | --- |
| **模型名称** | 必填 |
| **描述** | 可选 |
| **模型类型** | `Pretrained` 或 `Fine-tuned`（必填） |
| **类别数** | 须与模型输出维度一致；默认 `4` |
| **模型文件** | `.pt` 或 `.pth` 文件（拖拽或文件选择器） |

3. 点击 **上传**。

新模型以**草稿**状态出现，仅对你可见。

::: warning 需要 state-dict 格式
平台要求 PyTorch **state dict** — 即 `torch.save(model.state_dict(), path)` 的输出。使用 `torch.save(model, path)` 保存的完整对象文件将在加载时失败。state dict 须兼容项目的 `GCNNet` 架构（参见 [`backend/mcc_gcn/models/gcn.py`](https://github.com/PolarSnowLeopard/MCC-GCN-App/blob/main/backend/mcc_gcn/models/gcn.py)）。
:::

### 发布模型

要使草稿模型对平台所有用户可见：

1. 找到目标模型卡片。
2. 点击 **发布**。
3. 状态从 `Draft` 变更为 `Published`。

::: info
当前版本中发布为单向操作。如需将已发布模型恢复为草稿状态，请联系管理员。
:::

### 删除模型

针对你自己的非内置模型：

1. 点击模型卡片上的 **删除**。
2. 确认操作。

::: warning
- **内置模型不可删除。**
- 删除将永久移除服务器上的权重文件。已删除模型产生的预测结果仍可在 [历史记录](./history) 中查看，但该模型无法再用于新预测。
:::

## 空状态

若模型库显示为空，说明：

- 你没有自己的模型，**且**
- 不存在内置模型（管理员未运行 `seed_builtin_model` 管理命令）。

正常部署下至少应有两个内置模型。若缺失请联系管理员。
