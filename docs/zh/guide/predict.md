# 单次预测

**预测** 页面用于"我有两个分子，把它们共结晶会发生什么？"——返回一个 4 分类标签和完整概率向量。

::: tip 进入页面
点侧边栏 🧪 **预测**。它也是登录后的默认落地页。
:::

## 页面结构

页面分两栏：

- **左**：输入面板，顶部有两个 Tab：
  - **自由预测** — 你自己的分子（默认）
  - **论文样本** — 论文中 64 对实验数据，一键即可预测
- **右**：结果面板。第一次预测前为空。

## 工作流 A：自由预测

### 1. 选择模型

**选择模型** 下拉框列出对你可见的所有模型：

- 内置模型（`MCC-GCN Pretrained v1`、`MCC-GCN v1`）
- 你自己微调的模型
- 其他用户已发布的模型

每条都带一个 Tag — `Pretrained`（蓝色）或 `Fine-tuned`（绿色）。日常预测推荐用 **`MCC-GCN v1`**（已微调的生产模型）。

### 2. 选输入方式

模型下拉框下方有内层两个 **输入模式** Tab：

#### SMILES 输入（默认）

如果你已经有 SMILES，最快的路径。

| 字段 | 输入 |
| --- | --- |
| **API 分子 → SMILES** | 活性药物成分（API）的 SMILES |
| **共晶分子 → SMILES** | 共晶分子的 SMILES |

::: tip 在哪儿找一个分子的 SMILES
在 **PubChem** 上搜该分子 → 在「Names and Identifiers」一节里找 *Canonical SMILES*。RDKit 接受绝大多数标准 SMILES。
:::

#### 名称 / CAS 输入

如果手头没有 SMILES：

1. 切到 **名称 / CAS 输入** Tab。
2. 在 API 字段输入英文化合物名（如 `Salicylic acid`）或 CAS 号（如 `69-72-7`）。
3. 点 **查询**。系统会调用 PubChem，成功后下方显示解析到的 SMILES。
4. 对共晶分子重复同样操作。

::: warning
**不支持中文名**——请使用英文名或 CAS 号。
如果分子不在 PubChem 上，会看到 *"未找到分子"* 提示。这种情况下回退到 **SMILES 输入** Tab。
:::

### 3. 预测

点底部蓝色 **预测** 按钮。

- 默认模型推理大约 1 秒。
- 字段为空、SMILES 不合法等校验错误会以右上 toast 形式提示。

## 工作流 B：论文样本

用于复现论文实验或快速尝试：

1. 切到 **论文样本** Tab。
2. 选模型（与「自由预测」相同的下拉框）。
3. 在两个下拉框中选 **API 分子** 和 **共晶分子**。共晶分子下拉框可搜索 — 直接打字过滤 64 个候选。
4. 解析后的 SMILES 显示在下拉框下方供核对。
5. 点 **预测选定分子对**。

## 读结果

预测完成后，右栏会出现：

- **顶部 Hero 块** — 类别编号（`Class 0`–`Class 3`）、人类可读标签（`Negative` / `Salt` / `Cocrystal` / `Solvate`）、**置信度**（4 类概率最大值的百分比）。
- **概率柱状图** — 每个类别一行，带颜色的进度条 + 右侧的精确百分比。
- **Meta 块** — 实际送进模型的 API 与 Coformer SMILES（在你用了名称查询时，可用来确认模型看到的是不是你期望的分子）。

预测结果会自动归档到 [历史记录](./history)。

## 常见错误

| 提示 | 处理 |
| --- | --- |
| *"请选择模型"* | 在 **选择模型** 下拉框选一个。 |
| *"请输入或查询 API SMILES"* | 至少有一个分子字段为空。 |
| *"未找到分子"* | 名称/CAS 不在 PubChem 上。换近义名，或者直接粘贴 SMILES。 |
| *"预测失败"* | SMILES 语法上有效但 RDKit 无法构建图（如非法芳环）。从 PubChem 取规范 SMILES 再试。 |

## 小技巧

- 想验证平台是否正常？点表单顶部 **加载示例数据 (KPX + 水杨酸)** 即可一键填入已知有效的分子对。
- **双向推理**：平台内部会同时跑 `(API, Coformer)` 和 `(Coformer, API)` 两个方向，对 softmax 取平均，你不需要手动交换。
- 即使预测为 `Cocrystal`，也不能 *保证* 真的会形成共晶；用概率值来给候选排序、辅助实验决策。
