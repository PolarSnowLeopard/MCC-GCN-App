# 单次预测

**预测**页面用于回答以下问题：*给定两个分子，最可能的共结晶结果是什么？* 平台返回四分类标签及完整概率向量。

::: tip 导航
在侧边栏选择 **预测**。该页面也是登录后的默认着陆页。
:::

## 页面布局

页面分为左右两栏：

- **左栏** — 输入面板，顶部有两个标签页：
  - **自由预测** — 输入自己的分子（默认）
  - **论文样本** — 已发表研究中的 64 组实验分子对，可直接用于快速评估
- **右栏** — 结果面板（首次预测前为空）

## 自由预测工作流

### 步骤 1 — 选择模型

**选择模型**下拉菜单列出当前账号可见的所有模型：

- 内置模型（如 `MCC-GCN Pretrained v2`、`MCC-GCN v1`）
- 你自己的微调模型
- 其他用户已发布的模型

每个条目带有标签：`Pretrained`（蓝色）或 `Fine-tuned`（绿色）。日常推理推荐使用 **`MCC-GCN v1`**（生产级微调模型）。

::: info
若未选择模型，点击 **预测** 时平台将自动选择内置微调模型。
:::

### 步骤 2 — 输入分子对

模型选择器下方提供两种输入模式，以内层标签页切换。

#### SMILES 输入

当已有 SMILES 字符串时，这是最直接的路径。

| 字段 | 说明 |
| --- | --- |
| **API 分子** | 活性药物成分的规范 SMILES |
| **Coformer 分子** | 共晶配体的规范 SMILES |

::: tip 获取 SMILES 字符串
在 [PubChem](https://pubchem.ncbi.nlm.nih.gov/) 搜索目标化合物，在 *Names and Identifiers* 部分找到 *Canonical SMILES*。平台的 RDKit 解析器接受大多数标准 SMILES 格式。
:::

#### 名称 / CAS 输入

如果手头没有 SMILES，平台可通过化合物名称或 CAS 号进行解析。

1. 切换到 **名称 / CAS** 标签页。
2. 在搜索框中输入化合物的**英文名称**（如 `Salicylic acid`）或 **CAS 号**（如 `69-72-7`）。
3. 点击 **查询**。平台通过后端代理依次查询多个化学数据库（PubChem、NIH NCI Cactus、OPSIN）。查询成功后，解析到的 SMILES 会自动填入下方的可编辑输入框中。
4. 检查结果，如有需要可手动编辑 SMILES。
5. 对第二个分子重复上述操作。

::: warning
- 仅支持**英文名称**和 **CAS 号**，中文化合物名称无法解析。
- 若所有上游数据库均未识别该查询，将显示 *"未找到分子"* 提示。请切换到 **SMILES 输入** 标签页手动输入。
:::

### 步骤 3 — 执行预测

点击表单底部的 **预测** 按钮。

- 典型推理时间约 1 秒。
- 校验失败（字段缺失、SMILES 不可解析）将通过提示通知。
- 若两个 SMILES 字段均为空，将显示警告提示完善表单。

## 论文样本工作流

用于复现已发表的实验结果或快速基准测试：

1. 切换到 **论文样本** 标签页。
2. 选择模型（与自由预测共用同一下拉菜单）。
3. 从两个下拉菜单中分别选择 **API 分子** 和 **Coformer**。Coformer 列表支持搜索——输入文字即可筛选 30 个候选项。
4. 两个选项的解析 SMILES 显示在下拉菜单下方供核对。
5. 点击 **预测**。

## 解读结果

预测完成后，右栏显示以下内容：

| 区域 | 内容 |
| --- | --- |
| **分类结果** | 预测类别编号（`Class 0`–`Class 3`）及其标签（`Negative`、`Salt`、`Cocrystal`、`Solvate`） |
| **置信度** | 四类概率的最大值，以百分比表示 |
| **概率柱状图** | 每个类别一行，带颜色条和精确百分比 |
| **输入摘要** | 送入模型的 API 和 Coformer SMILES，便于确认解析结果 |

预测结果自动持久化到 [历史记录](./history)。

## 常见错误信息

| 提示信息 | 处理方式 |
| --- | --- |
| *"请选择模型"* | 从下拉菜单选择模型，或直接点击"预测"自动选择。 |
| *"请补全两侧分子的 SMILES"* | 至少有一个 SMILES 字段为空，请输入或查询两个分子。 |
| *"未找到分子"* | 上游解析器未识别该名称或 CAS 号。尝试同义词、改用 CAS 号，或直接粘贴 SMILES。 |
| *"预测失败"* | SMILES 语法有效但 RDKit 无法构建分子图（如畸形环系统）。请从 PubChem 获取规范 SMILES。 |

## 技术说明

- **双向推理**：平台同时评估 `(API, Coformer)` 和 `(Coformer, API)` 两种分子顺序，然后对 softmax 输出取平均。这补偿了图特征化的非对称性。
- **概率化输出**：65% 置信度的 `Cocrystal` 预测与 95% 的预测有本质区别。建议使用概率向量对候选分子进行优先级排序，辅助实验决策，而非仅依赖类别标签。
